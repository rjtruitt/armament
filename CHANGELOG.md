# Changelog

All notable changes to Armament will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial alpha release
- Multi-provider LLM support (Anthropic, OpenAI, Bedrock, Gemini, Ollama, OpenRouter, Replicate)
- IRC-style multi-agent channel management
- BBS-style retro terminal UI
- MCP (Model Context Protocol) integration
- Budget tracking and cost management
- Context persistence (save/load conversations)
- Workflow automation engine
- Multiple themes (ansi, red, fire, ice, pro)
- Built-in tools (file operations, code execution, web scraping)
- Interactive setup wizard
- Comprehensive documentation

### Known Issues
- Requires local file dependencies (sibling directories)
- Not yet published to npm
- Some themes (green, purple, synthwave, midnight) only available for banner/loading screens
- Documentation references need cleanup

## [0.1.0] - 2025-01-XX (Planned)

### Added
- First public alpha release
- Core functionality stable
- Documentation complete

### Fixed
- Documentation inconsistencies
- Missing configuration examples
- Theme availability clarified
